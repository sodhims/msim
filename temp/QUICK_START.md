## 🔌 INTEGRATION EXAMPLES

### Example 1: Use in Simulation
```csharp
// Get travel time from distance matrix
double travelTime = DistanceCalculator.GetTravelTime(
    distances, 
    fromMachineId: 1, 
    toMachineId: 3
);

// Add material handling delay to simulation
part.TravelTime = travelTime;
```

### Example 2: Optimize Layout
```csharp
// Evaluate current layout
var routings = GetProductRoutings();
double currentScore = DistanceCalculator.EvaluateLayoutEfficiency(
    distances, routings
);

// After rearrangement
RecalculateDistances();
double newScore = DistanceCalculator.EvaluateLayoutEfficiency(
    distances, routings  
);

// Lower score = better layout
Console.WriteLine($"Improvement: {currentScore - newScore:F2}m");
```

### Example 3: Generate Reports
```csharp
// Get layout statistics
var stats = DistanceCalculator.CalculateStatistics(distances);
Console.WriteLine(stats.ToString());

// Export to CSV for Excel analysis
string csv = DistanceCalculator.GenerateDistanceMatrixCSV(
    distances, machineNames
);
File.WriteAllText("layout_analysis.csv", csv);
```
